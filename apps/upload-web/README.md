# upload-web · 网页版上传（可选）

单文件、零依赖、零构建。**这不是主形态**，存在的意义有两个：

1. 原生 App 还没做时先跑通全链路
2. 应急兜底——任何设备打开浏览器就能传

## 文件

| 文件 | 用途 |
|---|---|
| `upload.html` | 上传页：粘贴 / 拖拽 / 拍照，多图 + 备注 + 日期 |
| `today.html` | 电视端临时页面：卡片列表 + 全屏看图（原生 App 做好后可删） |

## 用法

由 Go 服务直接托管，`http://<nas-ip>:8080/upload.html`。

也可以本地直接打开（`file://`），会自动进入演示模式，方便看交互。

## 已实现

- 全页面监听 `paste`，截图直接 `⌘V`
- 拖拽、多选、最多 6 张
- 提交即走，不等待识别
- 最近上传列表 + 失败重跑

## 注意

浏览器对 HEIC 支持不一致，手机上如果传不了，让 iOS App 转成 JPEG 再传。
