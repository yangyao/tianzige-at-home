# upload-web · 网页版上传（可选）

单文件、零依赖、零构建。**这不是主形态**，存在的意义有两个：

1. 原生 App 还没做时先跑通全链路
2. 应急兜底——任何设备打开浏览器就能传

## 文件

| 文件 | 用途 |
|---|---|
| `upload.html` | 上传页：粘贴 / 拖拽 / 拍照，多图 + 备注 + 日期 |
| `today.html` | 电视端临时页面：卡片列表 + 全屏看图（原生 App 做好后可删） |

## 用法

由 Go 服务直接托管，`http://<nas-ip>:8080/upload.html`。

本地直接打开（`file://`）需填写 NAS 地址；网络失败不会自动切到假数据。只有显式添加 `?mock=1` 才启用演示模式。

## 已实现

- 全页面监听 `paste`，截图直接 `⌘V`
- 拖拽、多选、最多 6 张
- 提交即走，不等待识别
- 最近上传列表 + 失败重跑

## 注意

浏览器对 HEIC 支持不一致，手机上如果传不了，让 iOS App 转成 JPEG 再传。

## AI 服务设置

在上传页下方展开“AI 服务设置”，或打开 upload.html#aiSettings。
支持 OpenAI 兼容 Chat Completions（需视觉模型）和 Z.AI/GLM 参数预设。
填写 API 地址、模型、密钥，可先测试再保存。只在 NAS 存储密钥，保存后不回显。
留空保留现有密钥；更换 API 地址需重新填写。无密钥本地模型可以显式选择无需密钥。
保存后所有客户端的新识别任务立即使用这组配置，已有作业保持不变。
从 file:// 或另一个站点打开时，请改为直接访问 NAS 上传页进行设置。
