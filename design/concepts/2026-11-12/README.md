## 评审与落地注意

这些是视觉概念图，不是可直接安装的应用资源或逐像素实现规格。图内黑板照片和作业内容均为生成的示例。

- 正式图标需要重新输出独立方形资源及 320×180 横幅，检查各尺寸的田字格线宽、封闭边界和品牌一致性；展示图中的横幅比例与标题布局仍需按实际槽位校准。
- 手机图中纵向照片占用较大；实现时按规范使用紧凑横向缩略图条，并保持上传按钮在底部安全区上方。
- Mac 图的配文占位文字生成成了“想对老师说点什么…”，应改为“可以粘贴老师的补充说明”，该字段用于老师原配文。
- 上传收到确认后才能显示“收到 N 张，处理完电视上就有”，不能提前承诺电视已显示；失败保留图片并提供重试。
- 这轮未画 Web 专用上传记录与失败重识别界面。
