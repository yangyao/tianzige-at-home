# 设计系统

> 机器可读版本：[`tokens.json`](tokens.json)。各端**不要自己发明色值和字号**，从这里取。
> 电视端布局细节看 [`04-电视端UI.md`](../docs/04-电视端UI.md) 和 [`tv-ui-design.html`](tv-ui-design.html)。

## 1. 一句话原则

**客厅里三米外能看清，比好看重要。** 所有取舍都服从这一条：字号偏大、对比偏强、元素偏少。

## 2. 色彩

品牌意象来自教室：**黑板绿做底，粉笔白做字，粉笔黄做强调，小红花红做点缀。上传端手机采用系统深浅色，浅色底使用暖白 #FAF9F6；手机主按钮用绿色 #326B50 / #3E7A5E。**

| Token | 值 | 用在哪 | 不要用在哪 |
|---|---|---|---|
| `bg.base` | `#14181C` | 页面底 | — |
| `bg.surface` | `#1D2329` | 卡片、面板 | — |
| `bg.raised` | `#262E36` | 悬停态、输入框 | — |
| `bg.overlay` | `rgba(0,0,0,.86)` | 全屏看图 | — |
| `text.primary` | `#F2F5F8` | 正文、标题 | — |
| `text.secondary` | `#A8B2BE` | 副标题、说明 | 正文（对比不够） |
| `text.dim` | `#6F7B88` | 键位提示、时间戳 | 任何需要读的内容 |
| `accent` | `#E9B44C` | **焦点态、选中日期、强调数字** | 大面积铺底 |
| `accent.ink` | `#1A1206` | accent 上的文字 | — |
| `brand` | `#3E7A5E` | 图标底、品牌点缀 | 文字（对比不足） |
| `flower` | `#D9544D` | **「这天有作业」圆点、「3 天前」角标** | 错误提示（会和品牌色混） |
| `ok` | `#4CAF7D` | 识别成功、已完成 | — |
| `warn` | `#E9A23B` | 识别中、待确认 | — |
| `error` | `#D9544D` | 识别失败 | — |
| `line` | `rgba(255,255,255,.09)` | 分割线、卡片描边 | — |

**为什么深色**：晚上客厅开一盏灯，白底电视会像手电筒。深色底让孩子的注意力落在图片上。

**为什么强调色是粉笔黄而不是蓝**：蓝色在所有电视上的表现差异很大（廉价面板偏紫），
暖黄在低端面板上也稳，而且和黑板绿是天然搭配。

## 3. 字号阶梯

三套场景，不要混用。电视的 1px ≠ 手机的 1px。

### 电视（1080p，观看距离 2.5–3.5m）

| Token | px | 字重 | 用在哪 |
|---|---|---|---|
| `tv.display` | 72 | 700 | 空状态主文案「今天还没有作业」 |
| `tv.h1` | 52 | 700 | 页面标题「今天的作业」、科目标题 |
| `tv.h2` | 42 | 600 | 作业条目正文、日期数字 |
| `tv.body` | 34 | 400 | 段落说明、备注 |
| `tv.caption` | 25 | 400 | 键位提示、「仅供参考」 |
| `tv.min` | 22 | 400 | **绝对下限，再小就不许用** |

换算参考：`tv.h2` 的 42px 在 3 米外的视角 ≈ 手机上的 16px。

### 手机 / 桌面（上传端）

| Token | px | 用在哪 |
|---|---|---|
| `ui.title` | 22 | 页面标题 |
| `ui.body` | 15 | 正文、输入框 |
| `ui.caption` | 13 | 辅助说明 |
| `ui.min` | 12 | 下限 |

**上传端不要跟着电视放大**：手机在手里 30cm，42px 是灾难。两套字号是刻意分开的。

### 字重
只用 400 / 600 / 700。中文字体在电视上 500 和 600 几乎看不出差别，多一个档只会让实现者纠结。

### 字体
- Android / TV：`Noto Sans CJK SC`，回退系统默认
- iOS / macOS：`PingFang SC`
- Web：`system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`

不打包自制字体：中文字体文件动辄 10MB+，收益远小于成本。

## 4. 间距

8 的倍数，只有这四个例外允许 4：

| Token | px |
|---|---|
| `space.1` | 4 |
| `space.2` | 8 |
| `space.3` | 12 |
| `space.4` | 16 |
| `space.5` | 24 |
| `space.6` | 32 |
| `space.7` | 48 |
| `space.8` | 64 |

电视端最小间距是 `space.5`（24），小于这个在 3 米外看起来就是「粘在一起」。

## 5. 圆角与描边

| Token | 值 | 用在哪 |
|---|---|---|
| `radius.sm` | 8 | 输入框、小标签 |
| `radius.md` | 12 | 卡片 |
| `radius.lg` | 20 | 大图容器、电视上的主卡片 |
| `radius.full` | 999 | 胶囊按钮、圆点 |

描边：普通卡片 `1px line`，焦点卡片 `4px accent`。

## 6. 焦点态（只对电视和键盘操作）

这是 TV 端**唯一**需要精心设计的交互状态。规则：

```
未选中：卡片 bg.surface + 1px line + 无阴影
选中  ：卡片 bg.surface + 4px accent 边框 + 外发光 0 0 0 8px rgba(233,180,76,.16)
        整体 scale(1.03)，过渡 120ms ease-out
```

三条硬要求：

1. **焦点必须能一眼找到**。孩子坐在沙发上，遥控器按一下，必须立刻知道现在选的是哪张。
2. **焦点移动不能有惯性**。按住方向键连跳三格，松手时停在哪就是哪，不做缓动追赶。
3. **同一时刻全局只有一个焦点**。不允许出现「日期条有焦点、内容区也有焦点」的情况——这是 TV 应用最常见的混乱来源。

## 7. 动效

只允许两种，其余一律不加：

| 场景 | 时长 | 曲线 |
|---|---|---|
| 焦点移动 | 120ms | `ease-out` |
| 面板/大图出现 | 200ms | `ease-out`，从 `scale(.96)` + `opacity 0` 起 |

不做：页面切换动画、列表逐项淡入、加载骨架屏的呼吸效果。
**电视上的动画一律显廉价**，而且低端芯片会掉帧，掉帧比没动画难看得多。

## 8. 图标与应用名

| 项 | 文件 | 说明 |
|---|---|---|
| 主图标 | `app-icon.svg` | 1024×1024，所有平台从这里导 |
| TV 横幅 | `app-icon-banner.svg` | 320×180，Android TV launcher 专用 |
| 导出 PNG | `icons/` | 各平台所需尺寸 |

图标构成：**黑板绿圆角底 + 完整白色田字格外框与横竖中线 + 右下格内的小红勾**。
外框使用独立的闭合矩形，不能用断开的折线路径；红勾放在格内，不遮住边线。
不用文字、不用铅笔、不用书本——那些在 48px 下都会糊成一团，只有「格子 + 勾」还能认出来。

应用名统一为 **家里的田字格**。副标题（各平台可加）：

- TV：`今日作业`
- iOS / macOS：`课后作业`
- Web：`作业上传`

## 9. 文案规范

这条容易被忽略，但它是「孩子能不能自己用」的关键。

| 场景 | 写这个 | 不写这个 |
|---|---|---|
| 今天没作业 | 今天还没有作业 / 老师发出来之后，这里会自己出现 | 暂无数据 / 空 |
| 识别中 | 正在识别，先看图 / 图是准的 | 加载中… |
| 识别结果 | 识别结果，仅供参考 · 以原图为准 | OCR 结果 |
| 上传成功 | 收到 3 张，处理完电视上就有 | 上传成功，正在处理中 |
| 识别失败 | 这次没识别出来 / 图片已经存好了，点重试就行 | 错误：OCR failed |

原则：**主文案说结论，副文案给出路。** 不要用技术词（OCR、批次、状态码），
不要用「失败」「错误」当第一句。

## 10. 各端差异速查

| | 电视 | 手机 | 桌面 | Web |
|---|---|---|---|---|
| 输入方式 | 遥控器（4 方向 + OK + 返回） | 触摸、相机、相册、剪贴板 | 拖拽、⌘V、文件选择 | 拖拽、⌘V、文件选择 |
| 字号档位 | `tv.*` | `ui.*` | `ui.*` | `ui.*` |
| 焦点 | **必须做，且只有一个** | 无 | 键盘 Tab | 键盘 Tab |
| 滚动 | **不允许**（一屏放下或翻页） | 允许 | 允许 | 允许 |
| 深色 | 强制 | 跟随系统 | 跟随系统 | 强制 |
| 主操作 | 看 | 传完就走 | 传完就走 | 传完就走 |
