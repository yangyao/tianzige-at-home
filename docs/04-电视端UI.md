# 电视端 UI

2026-11-12 更新：只呈现日期、作业原图与作业内容；不常驻显示同步状态、同步时间或遥控器说明。
小学生作业量有限，各学科一起分组展开，不用 Tab，不要求孩子切换学科。

## 布局

1920×1080 设计坐标，按屏幕高度缩放。顶部标题与日期，下方为本周日期条。
没有文字时直接看原图；有文字时左图右文，语文、数学、英语等有作业的科目同时展开。
不显示空白科目或服务器内部状态。原图 contain 完整显示，不裁切。
照片与内容之间用留白分组，作业正文按 1080p 的 42px 设计。

## 交互

日期、翻周箭头与照片使用原生空间焦点搜索，同一时刻只有一个焦点描边。
选中的日期保留背景色与数字颜色；只有真实焦点显示暖黄描边。

- 方向键在可见日期与照片之间移动，日期获得焦点时显示当天全部作业。
- 照片上确认打开原图，返回关闭。长图可以上下滚动。
- 翻周箭头确认切换相邻周。
- 菜单进入设置，首页返回进入退出确认。

这些行为属于开发文档，不写成屏幕上的操作指南。

## 数据更新

断网保留缓存，标题依据实际日期计算，避免把昨天缓存叫作今天。
仅前台轮询：等待文字时约 4 秒，已有结果时约 5 分钟。刷新后更新日期条作业标记。

本轮只用已有 tv34 模拟器验收。运行截图存本地 capture/，不把用户原图提交到 Git。
