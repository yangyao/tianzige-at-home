# 上传端排版检查

## 1. Web 桌面日期行：已修复

用户截图中的“作业日期”被挤成两行。
原因是元素改成 label 后仍只有 span 匹配单行样式；input 的 width:100% 又参与同一行的 flex 计算。

改为 label 不收缩且不换行，输入框使用剩余空间并允许自身收缩。
同时约束页头品牌图标和名称，防止窄屏标题被挤压。

已使用独立无头 Chrome 打开真实 NAS 上传页，保存修复前后截图。

实际检查了空态及导入用户真实作业照片后的界面。
