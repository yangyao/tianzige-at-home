# 本轮验收记录 · 2026-11-12

## 实作结果

- Android 复用上级 navidrome-tv 的构建矩阵；补齐原仓库遗漏的数据模型、网络、缓存、设置模块。
- 修正 data/ 忽略规则误伤源码目录，所有 .private 目录与运行数据均不入库。
- iPhone / Mac 上传页采用新设计，正式品牌图标入资源目录。
- 田字格外框使用独立闭合矩形，已从实际 Mac AppIcon.icns 提取验证左边线。
- 电视按用户最终反馈去掉同步状态、时间、遥控器教学文案和科目 Tab；全部科目同屏呈现。
- Go 用现有 1.20.5 构建纯静态 arm64，部署到真实 aarch64 NAS 的独立应用目录。
- Z.AI 密钥由私有文件读取，默认 glm-5.3-flash，不进入源码或安装包。

## 边界

- 用户改为模拟器之前已完成一次真机 APK 安装；随后没有启动或配置真机，交互验收均在模拟器。
- iOS 尚未在 iPhone 签名安装；未签名 zip 不能直接安装。
- NAS 当前为用户级常驻服务，未注册 QPKG 的系统开机自启。
- QQ 自动抓取仍是 README 中后续里程碑，本轮没有新增后台采集任务。
- AI 调用成功不代表手写识别逐字准确，也不等于验证了 Z.AI 控制台账单。
