# 用 QQ 机器人传作业

*这是本家庭最常用的上传方式：老师把作业发到 QQ，转发给机器人就完事了。*

## 它是什么

Mac mini 上跑着一个 [OpenClaw](https://openclaw.ai) 智能体，通过 QQ 官方 Bot API 接入 QQ。它已经学会了一套"传作业"的规则（见 [`skills/openclaw-qqbot-homework/AGENTS.md`](../skills/openclaw-qqbot-homework/AGENTS.md)）：收到图片先看一眼是不是作业，是就调 `/api/ingest` 传回家，不是就当普通聊天。

```
老师群里发作业图 → 你转发给 QQ 机器人 → 机器人调 /api/ingest → NAS 落盘并识别 → 电视能看到
```

不需要装任何 App，也不需要打开网页，QQ 里聊两句就行。

## 日常怎么用

在 QQ 里私聊机器人（或把机器人拉进家长群后 @ 它）：

| 你说 | 机器人做 |
| --- | --- |
| 直接转发作业图 | 看图判断是作业 → 传回家，归属当天 |
| "这是周二的作业" + 图片 | 传回家，归属到周二 |
| "传回家" + 图片 | 跳过判断直接传 |
| 发表情包、风景照 | 不上传，正常聊天 |
| 拿不准的图 | 先问"这张要传回家当作业吗？" |

一次可以转发多张（服务端一次最多收 6 张）。老师配的文字会作为 `note` 一起传，参与分科识别。

传完后机器人会回复批次号（batch_id）、日期和整理出的作业内容。传错了可以在 QQ 里让机器人撤回（它有权限调删除接口），或者到网页上传页的"最近上传"里删。

## 机器人侧的维护

机器人规则维护在两处，**改动时两边同步**：

- 仓库内（本仓库，作为源头）：[`skills/openclaw-qqbot-homework/AGENTS.md`](../skills/openclaw-qqbot-homework/AGENTS.md)
- 运行处：Mac mini 的 `~/.openclaw/workspace/AGENTS.md`（OpenClaw 每轮对话读取的生效副本）

当前部署信息（仅家庭内网有效）：

| 项 | 值 |
| --- | --- |
| OpenClaw 所在机器 | Mac mini（`192.168.2.123`），LaunchAgent `ai.openclaw.gateway` 常驻 |
| homework-server 地址 | `http://192.168.2.196:18086`（NAS 上用户级常驻服务） |
| QQ Bot | QQ 开放平台 AppID `1906395801`，qqbot 插件 WebSocket 网关接入 |

常见操作都在 Mac mini 上进行：

```bash
# 看机器人日志（QQ 收发、上传、报错都在这里）
tail -f ~/Library/Logs/openclaw/gateway.log

# 重启网关（改完配置后）
openclaw gateway restart

# 改机器人规则后无需重启，下一条消息自动生效
```

## 排错

| 现象 | 原因与处理 |
| --- | --- |
| 机器人不回消息 | `openclaw gateway status` 看网关是否在跑；LaunchAgent 未加载就 `openclaw gateway install` |
| 回复"Billing problem" | zai 插件默认指向普通端点，Coding 套餐 key 需要 `models.providers.zai.baseUrl` 设为 `https://api.z.ai/api/coding/paas/v4` |
| 说"重复了" | 服务端按图片 sha256 软去重，同一张图之前传过，不是故障 |
| 日期归错天 | 机器人漏传 `date` 参数。让它重传时要带上日期词；规则见 skills 文件第 3 条 |
| 图片没识别出科目 | 服务端 AI 设置里模型需支持视觉输入，见 [AI 配置](./07-AI配置.md)；历史批次可让机器人或网页触发 rerun |

## 和其他上传方式的关系

网页上传（`/upload.html`）、iPhone / Mac 客户端适合"主动拍、主动传"；QQ 机器人适合"作业已经在群里，顺手转一下"。三者走的是同一个 `/api/ingest`，电视端无差别展示。
