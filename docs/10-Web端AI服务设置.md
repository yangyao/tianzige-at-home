# Web 端 AI 服务设置

入口：上传页下方“AI 服务设置”，或直接访问 /upload.html#aiSettings。

## 使用

1. 选择 OpenAI 兼容，或 Z.AI / GLM 参数预设。
2. 填写基础 API 地址（也接受完整 /chat/completions 地址）、模型和密钥。
3. 可先测试连接，再保存并应用。测试发送一张小图片，可能消耗少量模型额度。

模型必须支持 image_url 图片输入。同一个模型完成照片识别和按科整理。
纯文本模型、仅支持 Responses 的接口，以及不同鉴权格式的非兼容接口不能直接使用。
无密钥本地服务可显式勾选“此服务无需密钥”。

## 生效与存储

现有环境变量与私有 key 文件作为初始值，第一次在 Web 保存后以
数据目录 .private/ai-provider.json 为准。无需重启，新批次立即生效。
正在处理的批次保留原来的识别 / 分科模型组合，避免同一批次混用不同服务。
保存失败不改变正在使用的配置，测试也不修改配置或创建作业记录。

JSON 文件权限 600、目录 700，静态站点无法访问。GET 与 PUT 响应只返回
has_api_key，不回显密钥。留空只在同一 API 地址保留旧密钥；
换地址需新密钥，避免自动把旧服务密钥发送给另一家服务。

管理接口只接受 NAS 上传页同源请求；普通上传接口的跨域行为不变。
浏览器不把 AI 密钥写入 localStorage。
