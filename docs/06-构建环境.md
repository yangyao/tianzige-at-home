## 构建

在仓库根目录：

```sh
sh scripts/export-icons.sh
sh scripts/build-tv.sh
sh scripts/build-apple.sh
make -C services/homework-server test bundle
```

TV 脚本检查现有 JDK / SDK 后，以 --offline 编译、跑单元测试与 lint。
图标导出复用已有 librsvg、ImageMagick。Apple 工程由现有 XcodeGen 生成，
两个 project.yml 是配置真源。Mac 包为本地 ad-hoc 签名，iOS 包为未签名设备构建。
在 iPhone 安装仍需 Xcode 配置 Team。所有安装包放 dist/。

## NAS

通过 SSH 确认目标是 Linux aarch64，并实际运行 arm64 静态二进制。
NAS 不需要安装 Go、Node、Docker、SQLite 动态库或 tzdata。
时区使用固定 +08:00，数据为本地 SQLite WAL 和原图目录。

make bundle 默认只构建实际目标 arm64。当前 modernc.org/libc 1.49.3 的 Linux amd64
实现引用 Go 1.21 才有的 slices，因此本机 Go 1.20.5 不能构建 amd64。
将来确有 amd64 目标时，使用已有 Go 1.21+ 执行 make bundle-amd64 GO=/实际/go路径。
本轮没有为无关架构下载新工具链。

部署见 [NAS 安装](../deploy/README.md)，AI 见 [AI 配置](07-AI配置.md)。
