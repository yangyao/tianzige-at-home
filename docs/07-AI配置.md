# Z.AI 识别与分科

默认模型 glm-5.3-flash，直接调用公开 Chat Completions，无需在 NAS 安装 Node 或 MCP 运行时。

## 配置

本机凭据位于 services/homework-server/.private/，所有 .private 目录均被 Git 忽略。
NAS server.env 示例：

```sh
TIANZIGE_OCR=zai
TIANZIGE_LLM=zai
Z_AI_BASE_URL=https://api.z.ai/api/coding/paas/v4
Z_AI_VISION_MODEL=glm-5.3-flash
Z_AI_API_KEY_FILE=/你的私有目录/zai.key
```

密钥文件仅包含密钥，权限 600、父目录 700。禁止复制进源码、安装包或示例配置。
也支持 Z_AI_API_KEY；配置文件路径后以文件为准，读失败不会偷偷使用其他凭据。
修改后重启，已有照片通过重新识别重跑，无需再次上传。

图像输入用 Base64 Data URL，temperature 1、thinking enabled、max_tokens 16384。
拒绝截断输出，保留原图与识别原文。没有密钥时报告 unconfigured，但原图仍可上传、保存和查看。
mock 只用于显式开启的离线测试。

## 官方依据

- [GLM-5.3-Flash](https://docs.z.ai/guides/vlm/glm-5.3-flash.md)：模型名、图片输入和 thinking 参数。
- [Coding Plan 接入范围](https://docs.z.ai/devpack/tool/others.md)：公开 endpoint 与支持工具范围。自建 NAS 后端不在官方工具清单内，调用成功不能表述成官方支持。
- [Key 管理](https://docs.z.ai/devpack/notice/api-key-management.md)：Standard、Coding Plan、Compatible key 的账单规则不同，不能仅凭 endpoint 推断扣费。

使用用户指定 Coding Plan 地址，不自动回退普通 API、不伪装其他客户端。
账户额度和实际账单需在 Z.AI 控制台核验。

## Web 切换服务

上传页底部展开“AI 服务设置”，选择 OpenAI 兼容或 Z.AI / GLM，填写地址、支持图片的模型及密钥。
API 基础地址与完整 /chat/completions 地址均可。保存后新任务即时使用，不需要重启 NAS 服务。

- 测试连接会发送一张小图片，可能消耗少量额度，但不会保存设置或产生作业记录。
- 密钥保存后不回显，字段留空在地址未变时保留原密钥。
- 换 API 地址后必须填写新密钥，避免将上一家服务的密钥发给另一家。
- 无密钥的本地服务可显式选择“此服务无需密钥”。
- 原有 Z.AI 环境配置作为初始值。第一次 Web 保存后，以 data/.private/ai-provider.json 为准，重启也保留。
- 配置文件权限为 600，目录 700；不在静态站点目录，不进入安装包或 Git。
- 正在处理的批次保留原来的识别和分科模型组合，新批次才使用新配置。
- AI 设置仅允许从 NAS 上传页同源管理；从其他站点或 file:// 页面管理会被拒绝。

提供的是 Chat Completions + image_url 的兼容能力；纯文本模型、仅提供 Responses 或其他协议的服务不能直接识别图片。
