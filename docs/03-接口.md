# 接口

Base URL：`http://<nas-ip>:8080`，仅局域网。

## 1. 上传

```
POST /ingest
Content-Type: multipart/form-data
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `files[]` | file | 是 | 1–6 张图片，jpg/png/heic |
| `note` | string | 否 | 老师配的那句话 |
| `date` | string | 否 | `YYYY-MM-DD`，默认今天 |

**响应（立即返回，不等识别）**

```json
{ "batch_id": 318, "status": "pending" }
```

> 图片已落盘即返回。OCR 与分科在后台进行。

## 2. 批次状态

```
GET /batch/{id}
```

```json
{
  "id": 318,
  "date": "2026-11-12",
  "status": "done",
  "subjects": [
    { "subject": "语文", "items": ["第 32 页 第 1—5 题", "朗读课文三遍"] },
    { "subject": "数学", "items": ["练习册 P18 第 1—6 题", "口算本一页"] }
  ]
}
```

`status`：`pending`（已存图）→ `ocr`（识别中）→ `parsing`（分科中）→ `done` / `failed`

## 3. 最近批次

```
GET /batches?limit=6
```

```json
[
  { "id": 318, "date": "2026-11-12", "time": "17:30", "count": 3, "status": "done" },
  { "id": 317, "date": "2026-11-12", "time": "17:02", "count": 1, "status": "failed" }
]
```

## 4. 重新识别

```
POST /batch/{id}/rerun
```

对已落盘的图片重新跑 OCR + 分科。**不需要重新上传。** 历史批次同样适用。

```json
{ "id": 318, "status": "pending" }
```

## 5. 电视端读取

```
GET /today?date=2026-11-12
```

```json
{
  "date": "2026-11-12",
  "items": [
    {
      "url": "/img/2026-11-12/1730_a1b2.jpg",
      "subject": "数学",
      "ocr": "练习册P18，口算本一页…",
      "stale": false
    }
  ]
}
```

- 日期缺省为今天
- `items` 为空 = 当天没有作业（前端显示空状态，不报错）
- `stale=true` 表示这条是上次缓存，或识别未完成（只给图）

## 6. 静态资源

```
GET /img/{date}/{filename}
```

## 7. 数据库

```sql
CREATE TABLE batch (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  date       TEXT NOT NULL,          -- 2026-11-12
  note       TEXT,                   -- 老师配文
  status     TEXT NOT NULL,          -- pending|ocr|parsing|done|failed
  created_at TEXT NOT NULL
);

CREATE TABLE image (
  id       INTEGER PRIMARY KEY AUTOINCREMENT,
  batch_id INTEGER NOT NULL REFERENCES batch(id),
  path     TEXT NOT NULL,            -- 相对路径
  sha256   TEXT,                     -- P2 去重用
  ocr_raw  TEXT                      -- OCR 原始文本
);

CREATE TABLE item (
  id       INTEGER PRIMARY KEY AUTOINCREMENT,
  batch_id INTEGER NOT NULL REFERENCES batch(id),
  image_id INTEGER,
  subject  TEXT NOT NULL,            -- 语文|数学|英语|其他
  content  TEXT NOT NULL,
  sort     INTEGER NOT NULL,
  done     INTEGER NOT NULL DEFAULT 0,  -- P2 打勾
  done_at  TEXT
);
```

## 8. 约定

- 所有时间用本地时区（`Asia/Shanghai`），不做 UTC 转换
- 错误统一返回 `{ "error": "..." }` + 4xx/5xx
- 不做鉴权；如果要，加一个固定的 `X-Token` 头即可
- 上传大小上限 20MB/张
