# 需求

## 1. 背景

老师每天下课前把当天作业写在黑板上，拍一张照片发到班级 QQ 群。

孩子记不住作业内容，只能拿大人的手机：解锁 → 打开 QQ → 找到班级群 → 往上翻 → 点开图片 → 放大看。大人手机不可能一直给孩子。

## 2. 目标

> 孩子放学回家，自己打开电视，就能看到今天的作业——原图 + 能看清的文字。

判断成功的标准只有一条：**孩子会不会自己去看**。技术上跑通不算成功。

## 3. 用户与场景

| 角色 | 场景 | 关心什么 |
|---|---|---|
| 孩子（小学） | 放学回家、写作业前 | 今天有几项、写什么、别漏了 |
| 家长 | 每天 17:30 前后收到老师消息 | 别让我再翻手机；孩子能自己搞定 |
| 家长（维护者） | 偶尔发现当天没同步 | 知道哪儿断了，能补一次 |

## 4. 功能需求

### 4.1 采集（P0）

| 编号 | 需求 | 优先级 |
|---|---|---|
| C-1 | 从 QQ 群自动下载当天的作业图片，上传到 NAS | P0 |
| C-2 | 网页手动上传：粘贴截图 / 拖拽 / 手机拍照，可多张 | P0 |
| C-3 | 同一天可多次上传，累加而不是覆盖 | P0 |
| C-4 | 上传后立即可离开，不等待识别 | P0 |
| C-5 | 查看最近上传记录与处理状态 | P1 |
| C-6 | 对失败的批次重新识别（不必重新上传） | P1 |
| C-7 | 重复图片自动跳过 | P2 |

### 4.2 解析（P0）

| 编号 | 需求 | 优先级 |
|---|---|---|
| P-1 | 图片 OCR 出文字（含黑板手写体） | P0 |
| P-2 | 结合老师配文，按科目拆分（语文 / 数学 / 英语 / 其他） | P0 |
| P-3 | 每科拆成若干「作业项」，可读、可勾选 | P1 |
| P-4 | 识别失败时降级：只存图，不做文字 | P0 |
| P-5 | 识别结果标注置信度，低的在电视上标记 | P2 |

### 4.3 电视端（P0）

| 编号 | 需求 | 优先级 |
|---|---|---|
| T-1 | 打开即今天，无需任何操作 | P0 |
| T-2 | 显示原图（可全屏放大） | P0 |
| T-3 | 显示 OCR 文字，字号远距离可读 | P0 |
| T-4 | ← → 切换日期，可看本周任意一天 | P0 |
| T-5 | ↑ ↓ 切换当天的不同图片 / 科目 | P0 |
| T-6 | 当天没有作业时给出明确提示 | P0 |
| T-7 | 显示历史（至少本周） | P1 |
| T-8 | 作业项打勾，记录完成状态 | P2 |
| T-9 | 断网时显示上次缓存的内容 | P2 |

## 5. 非功能需求

| 项 | 要求 | 说明 |
|---|---|---|
| 部署 | 单机、单二进制、局域网 | NAS 上 docker 或直接跑 |
| 依赖 | 除 OCR 外不依赖外部服务 | OCR 可先用云 API |
| 账号 | 无 | 家里局域网，不做登录 |
| 数据 | 全部留在 NAS | 只有 OCR 时图片会出网 |
| 并发 | 一个家庭（1–3 个孩子） | 不需要多租户 |
| 可用性 | **尽力而为** | 挂了就走回「问家长看手机」，无损失 |

> 可用性这条要写清楚：这不是服务，失败有天然兜底。**不建告警体系、不追求 SLA**，出问题人工重跑一次即可。

## 6. 约束

- 电视必须是 Android TV 系统（鸿蒙 / Tizen / webOS 装不了）
- 遥控器只有方向键、OK、返回，没有触屏、没有键盘
- 观看距离 2.5–3 米，正文小于 40px（@1080p）不可读
- NAS 可能是 ARM，OCR 本地化要视硬件而定

## 7. 里程碑

| 阶段 | 内容 | 出口标准 |
|---|---|---|
| M1 | Go 服务 + 网页上传 + 电视浏览器查看 | 手动传一张图，电视上能看到 |
| M2 | OCR + 分科 | 电视上图文并列，字能看清 |
| M3 | Android TV 原生 App | 遥控器四键可用，装上就能日常用 |
| M4 | Mac mini 自动采集 | 连续一周不需要手动补 |
| M5 | iOS / macOS 原生上传 | 手机上截图直接传 |

## 8. 明确不做

- 题库、练习、判分、讲题、给答案
- 家长监控 / 学习报告 / 时长统计
- 多班级、多学校、对外服务
- 直播课、视频课
